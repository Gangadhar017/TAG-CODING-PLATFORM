# TAG Coding Platform — Frontend

React + Vite frontend for the TAG Coding Platform.

**Author:** Gangadhar ([GitHub: Gangadhar017](https://github.com/Gangadhar017))

## Development
```bash
npm install
npm run dev        # starts at http://localhost:5173
```

## Production Build
```bash
npm run build      # outputs to ./dist
```

Copy `dist/*` into `../Backend/public/` for monolithic deployment.
